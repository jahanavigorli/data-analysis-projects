# Student CGPA Data Analysis 

## Overview

This project performs Exploratory Data Analysis (EDA) on student academic data using Python, Pandas, and Matplotlib.

## Objectives

* Identify missing values in student data.
* Apply different missing-value imputation techniques.
* Analyze CGPA statistics.
* Visualize the relationship between attendance and CGPA.
* Identify abnormal values and potential outliers.

## Technologies Used

* Python
* Pandas
* Matplotlib
* Excel Dataset

## Concepts Covered

* Data loading and inspection
* Missing value detection
* Mean imputation
* Median imputation
* Mode imputation
* Descriptive statistics
* Histogram visualization
* Line plots
* Scatter plots
* Boxplots and outlier detection

`student.xlsx`
